# Diagrams

- Exported images (`.png` / `.svg`) live in this folder, named `<level>-<name>.svg`, e.g. `c1-context.svg`, `c2-containers.svg`.
- Editable sources live in [`src/`](src/) (Mermaid `.mmd`, Structurizr `.dsl`, draw.io `.drawio`, or Excalidraw).

Render Mermaid sources with: `npx @mermaid-js/mermaid-cli -i src/c4-context.mmd -o c1-context.svg`
